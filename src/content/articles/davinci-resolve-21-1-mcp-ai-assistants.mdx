Blackmagic Design shipped DaVinci Resolve 21.1 on September 8, 2026, and the standout addition for anyone already using outside AI tools is a native MCP server built into Resolve Studio. Point Claude, Claude Code, or ChatGPT Codex at a project, and it can drive the actual application instead of just describing how you'd do something yourself.

## What changed

Resolve Studio 21.1's new MCP server covers project setup, timeline editing, the media pool, color grading, Fairlight audio, the render queue, and export. Setup happens from File, then Setup AI Assistants, which connects Resolve to Claude, Claude Code, or ChatGPT Codex.

In practice that means you can ask for something like a three minute highlight reel with every cut under a second trimmed out, rendered as H.265, and have the assistant actually execute it across the timeline, not just tell you how.

This ships inside a bigger 21.1 release. Blackmagic counts more than 100 new tools and controls in total, including a batch of new Fusion tools, but the MCP server is the part that changes how the app can be used, not just what it can do.

One limit worth flagging up front: this is a Studio feature. The free version of DaVinci Resolve doesn't include the MCP server or AI assistant integration.

## Why it matters for designers

This fits a broader pattern this year of creative tools opening themselves up to outside AI agents through MCP, rather than shipping their own bolted-on chat assistant. For motion and video work specifically, a lot of the tedious parts of editing, renaming and organizing media, standard export passes, rough assembly cuts, are exactly the kind of task you can describe in a sentence and hand off, freeing up actual editing time for the parts that need a human's judgment.

Claude Code support in particular opens the door to more than one-off requests. Because it's a code-capable agent, it's plausible to script repeatable batch workflows, consistent renders across a season of episodes, say, rather than re-prompting the same request project by project.

## What to watch out for

Blackmagic's release notes don't say what happens to project or media metadata when an outside AI assistant reads or acts on a Resolve project, whether anything about your timeline or footage leaves your machine to reach Claude's or OpenAI's servers. That's worth checking directly before pointing an agent at anything covered by an NDA.

We haven't tested this against a real project ourselves yet, so treat the sidebar as open questions rather than confirmed answers.
