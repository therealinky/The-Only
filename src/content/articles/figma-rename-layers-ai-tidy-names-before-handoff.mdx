Figma has two ways to name your layers with AI. There's the built-in Rename layers action, which picks names on its own, and there's the Figma agent, which you can ask to follow a naming convention. Most guides cover one or the other. This pulls together Figma's own documentation, a couple of independent write-ups, and recent forum reports, plus general Figma file-organization practice, into one approach. It's synthesized from published sources, not something we've run end to end on a real project.

1. **Finish the structure first, then name.** The built-in action only renames layers that still have Figma's default names, and it keeps anything you've already renamed. So naming works best near the end, once frames and groups have stopped moving around. Run it on a screen that's half built and you'll be running it again later anyway.

2. **Protect what you don't want touched.** Figma's help page says it skips hidden and locked layers, so lock any layers whose names have to stay exactly as they are, like layers a developer has already wired up or ones a plugin depends on. That's the closest thing the built-in action has to an exclude list.

3. **Run Rename layers on one screen at a time.** Select a frame (or a handful of related layers), then right-click and choose Rename layers, or find it under Actions in the toolbar or in the quick actions menu. Figma says it looks at each layer's contents, its location, and how it relates to the other layers you selected. Selecting one screen at a time keeps that context focused and makes the results easier to check than a whole page in one go.

4. **Know what it will skip, and fix those by hand.** It renames frames, groups, text layers, rectangles with an image fill, and instances still using their component's default name. It doesn't rename anything nested inside an instance, individual vector shapes like ellipses, stars, and polygons, or rectangles without an image fill. A recent forum report adds layers placed inside a component's slot to that list. For instance sublayers, the fix is to name them once in the main component, so every instance picks them up.

5. **Use "Rename anyway" when it says there's nothing to do.** If every layer in your selection already looks named, Figma shows "No layers need renaming." Choosing Rename anyway runs it again regardless. The help page doesn't spell out whether that replaces names you set yourself, so try it on a duplicate of the frame first.

6. **Check what it did to duplicates.** If the same unnamed layer appears in several top-level frames, Figma renames the matching copies too, so prototype features like Smart animate and scroll position keep lining up. That's helpful, but click through a prototype afterward to make sure transitions still behave the way you built them.

7. **Layer a convention on top.** The built-in action picks its own wording. If your team uses a convention, you have two routes. The manual one is Figma's bulk rename (it doesn't use AI), which can add prefixes, suffixes, or numbers and supports regular expressions, good for consistent patterns like putting a section name in front of every layer. The AI one is the Figma agent: select layers, a frame, or a page, describe the convention in plain words (something like "name by component and state, lowercase with hyphens"), review, and refine in the same chat thread. The agent is the better fit when the rule depends on what each layer actually is. Bulk rename is better when the rule is purely mechanical.

8. **Do a quick handoff pass.** Open the frame in Dev Mode, or look at it the way a developer would, and scan the layer panel for leftovers: vectors still called "Vector," slot content, anything inside instances. Those are the gaps the steps above can't cover automatically.

## Why it matters for designers

Layer names used to be a courtesy. Now they do real work. Developers read them in Dev Mode, prototype settings use them to match layers across frames, and AI coding tools that read your file through Figma's MCP server or the agent see them too. A file full of "Frame 427" and "Group 12" is harder for all of them to make sense of.

The sources split on how much to automate. Figma's own pages push the agent, which can follow a convention. The independent guides mostly stick to the built-in action and treat naming conventions as a manual job for bulk rename. Both have a point. The built-in action is fast and predictable about what it skips, while the agent is more flexible but gives you something new to review every time, and it costs credits where the built-in action is free.

## What to watch out for

It isn't always reliable. Figma Forum threads from April and June 2026 describe Rename layers freezing the app or spinning and then closing without renaming anything, and Figma staff said in June that they were looking into a backend issue, with no fix recorded in those threads. If it hangs, try the browser version before assuming your file is the problem.

The skip list is longer than it looks. Vectors, layers inside instances, and slot content all stay as they were, and those are often the layers a developer actually needs to find. Plan a manual pass for them.

The agent's AI-chosen names are a draft, not a standard. If you go the agent route, review its names against your convention before handing off, and remember that every agent run draws on your AI credits. Figma's own solutions page still says the agent is free during an open beta, but that's out of date: Figma's credit FAQ says it left beta on October 6 and has used credits since. The built-in action is listed as free, so it's worth trying first. Check the sidebar for which plans include Rename layers.
