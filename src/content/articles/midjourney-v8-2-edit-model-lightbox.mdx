Midjourney's alpha changelog has been rolling out a new v8.2 edit model through September 2026, and it's a bigger shift than a typical point release: a real editor built directly into the image lightbox, rather than the separate, more limited editing flow Midjourney has offered before.

## What changed

With v8.2, opening an image in the lightbox gives you an editor where you can describe a change in plain language, attach up to four reference images to guide it, and see every edit made during that session lined up together instead of losing track of prior versions. The September 2 alpha changelog introduced the editor itself. A follow-up on September 16 refined the prompt flow (the bar now asks "What would you like to change?" once an image is attached) and added a grid view with hover previews for draft batches. Later alpha notes describe improvements to inpainting and outpainting specifically, targeting only the pixels you mean to change so repeated edits don't gradually degrade the rest of the image.

## Why it matters for designers

Iterative, targeted editing has been the weak point in most text-to-image tools compared to something like Photoshop: describe a change, get a mostly different image back, repeat. A lightbox editor that keeps a session's edit history in one place and supports genuine inpainting (change this one element, leave everything else untouched) moves Midjourney closer to a tool you can actually art-direct, instead of one you can only re-roll. The four-reference-image support helps for the same reason: it lets you say "like this, but change that" with visual references instead of trying to describe a precise change in words alone.

For illustration and concepting work specifically, this matters most at the refinement stage, after you've generated something in the right direction and need to push it toward a final version without regenerating from scratch and losing what was already working.

## What to watch out for

This is an alpha feature, not a general release. Expect it to change before it ships broadly, and don't assume today's behavior, or its eventual plan-tier availability, is final. We haven't run this through a real project ourselves yet, so treat the "before you use it" panel in the sidebar as unverified rather than confirmed. We'll follow up with a Test once the edit model is out of alpha and we've used it on actual work.
