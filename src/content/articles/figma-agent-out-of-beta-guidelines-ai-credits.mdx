Figma's on-canvas agent has spent the past several months in an open beta that didn't cost anything to use. That ended on October 6. The agent in Figma Design is now generally available, it picked up a few genuinely useful features on the way out, and every prompt now draws on your AI credits.

## What changed

Figma's release notes and launch post list the main additions:

- **Guidelines for libraries.** Library owners can upload markdown files to a Figma library with rules, best practices, and antipatterns for their design system. The agent reads them for extra context when it works with that library.
- **File search in chat.** You can ask the agent to find Figma files, and it's faster overall, according to Figma.
- **More ways to give it context.** You can attach Figma files to a conversation and paste frames or other nodes straight into a prompt as a reference.
- **Watching teammates' agents.** You can see a teammate's agent working on the canvas live.
- **Image model choice.** When you use the agent to edit an image on the canvas, you can now pick which image model does the work.
- **Generative plugins and custom skills.** Generative plugins are now generally available too, and custom skills (saved, shareable agent workflows) are now available on the Starter plan.

Figma also says output quality improved, and that the agent now wins in "~60%+ of our human-graded evals with professional designers." That's Figma's own internal testing, not an independent benchmark.

The cost side is in Figma's credit FAQ: the agent and Weave tools moved to general availability on October 6 and now share the same AI credit budget as Figma Make. Beta usage didn't count against credits.

## Why it matters for designers

Guidelines are the interesting part for anyone who runs a design system. Until now, getting an agent to respect your conventions meant hoping it inferred them from components. A markdown file that says "use this button for primary actions, never put two side by side, don't use raw hex values" gives the agent the same written rules a new hire would get. It's also a good excuse to write those rules down if your team never has.

The credit change matters just as much in day-to-day work. A lot of designers got used to the agent as a free sidekick for small chores: renaming layers, roughing out variants, tidying a frame. Each of those requests now has a cost, and since Figma says usage depends on how complex the prompt is and what the agent does, it's hard to predict what a task will cost before you run it.

## What to watch out for

The agent now shares a credit pool with Figma Make and other AI features, so heavy agent use can leave less for everything else. Keep an eye on your balance for the first couple of weeks, and if you're an admin, check how your team's usage lands before someone runs out mid-project.

Seat type matters. Figma's help center describes the agent as available on all plans, but only Full seats with edit access can have it make changes to a shared file; other seats can chat with it without editing. Anyone can have it edit their own drafts, and Figma's launch post calls availability on the Starter plan limited. How many credits come with your plan isn't spelled out in the FAQ, which points admins to their dashboard. Every seat gets a monthly allowance that resets each month, and admins can buy more.

If you're an admin on an Organization or Enterprise plan, there's a useful way to estimate what this will cost: Figma lets you download a CSV of your team's agent and Weave usage from the beta period, which shows how many credits that usage would have taken.

Guidelines only help if they're accurate and current. An outdated rules file can steer the agent toward patterns your team already dropped.

Data handling and rights weren't covered in what we read. The sidebar has the details.
