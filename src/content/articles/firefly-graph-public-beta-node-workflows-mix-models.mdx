Adobe is launching Firefly Graph as a public beta at MAX 2026. If you've seen ComfyUI-style node canvases and wondered whether you'd ever want one inside Adobe's world, this is that idea. It's based on Adobe's own pages and one news report. We haven't tried it ourselves.

## What changed

Adobe describes Graph as a node-based builder for connecting AI models, Creative Cloud tools, and assets into repeatable pipelines. Each node does one step, such as generating an image or editing a file, and its output feeds the next node. There's also a built-in AI Assistant that can help you build and tune a workflow from a plain-language request.

Adobe's page says you open it from the Firefly site with an Adobe ID and doesn't mention a waitlist. It names models from Google and OpenAI alongside Adobe's own, and offers ready-made workflows for things like storyboards, branding visualization, and blending layers, so you don't have to start from a blank canvas. In its MAX announcement, Adobe lists example uses like character studies, shot lists, and carrying brand guidelines across campaign assets.

Graph isn't brand new. A June report covered an earlier release for enterprise customers, with a signup survey for a beta aimed at Creative Cloud for teams. What's new this week is the public beta wording on Adobe's own page.

## Why it matters for designers

The pitch is repeatability. If you make the same kind of asset over and over, say a set of social crops from one hero image, a graph lets you build the steps once and rerun them with a different prompt or reference image. Changing a node changes the output, so you can tune one stage without redoing the rest.

It also means mixing models in one place instead of bouncing between tabs, which is something a lot of designers do by hand today.

## What to watch out for

It's a beta, so expect features and availability to change. Credits are the big one: a graph that chains several generative nodes can burn through them quickly, so check each node's cost before you run it.

The page is promotional and offers no independent performance data. The counts of how many nodes exist also differ between Adobe's own pages, so we've left that number out. Whether it replaces a node tool you already use is a fair question. In the June report, Forrester principal analyst Lisa Gately said that where Adobe differentiates is "in enterprise integration," connecting Graph to its other apps, not the canvas itself.
