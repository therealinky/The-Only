Dev Mode has always been the place to inspect a design: click a layer, read its properties, copy what you need. Figma's November 19 release note adds a second way in. You can now prompt the Figma agent from inside Dev Mode and ask it about the design instead. This is based on Figma's release note and help page. We haven't tried it ourselves.

## What changed

The release note lists three things you can ask for: compare versions of a design, get code snippets, and get download links so you can save assets in bulk.

Figma's help page for the agent fills in a bit more. It lists Dev Mode tasks like asking how a component's interactions work, finding layers that could use variables you already have, getting implementation advice such as a CSS grid or flexbox approach or a React snippet, seeing a version comparison as a visual diff or as a list of changes in the chat, and generating links to save icon components as SVGs or CSS for your variables.

Seats matter here. The help page says people with a Dev seat can chat with the agent without changing the design, while Full seats can also ask it to make edits. It also says Dev Mode isn't available on Starter plans or with View or Collab seats. The agent runs in Figma Design, in the desktop app or a browser.

## Why it matters for designers

The version comparison is the part designers will feel most. "What changed since the last handoff?" is a question developers ask constantly, and the honest answer usually lives in someone's memory or a pile of comments. If the agent can show a visual diff or a plain list of changes, that's less time spent walking someone through a file you redesigned on Tuesday.

It also gives developers a way to ask questions without asking you. Which variable should this spacing use? How is this component supposed to behave? That can mean fewer interruptions, or it can mean a confident wrong answer you don't hear about until review. Which one you get depends on how clean your file is.

And because Dev seats can only chat, not edit, a developer poking around with the agent can't accidentally move your layers.

## What to watch out for

It isn't free to use. The help page says the credits an agent run uses change with the complexity of the task, and it doesn't give fixed amounts. A big version comparison on a large file may cost more than a quick question, so if your team shares a credit pool, it's worth agreeing who uses it for what.

It can only explain what's in the file. If your components are detached, your layers are unnamed, or values are hard-coded instead of using variables, expect its answers and snippets to reflect that. The help page's own example of finding layers that could use existing variables is a hint at how often that's an issue.

The agent prepares downloads but doesn't export for you. The help page marks exporting assets as something it can't do directly. It generates links instead, so someone still has to download and check them.

Generated code is a starting point, not a spec. A React snippet or a flexbox suggestion still needs a developer to fit it into the real codebase, with its own components and conventions. The sidebar covers what we couldn't confirm about client files and code.
