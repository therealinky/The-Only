Autodesk Assistant, the built-in AI helper in Maya and 3ds Max, can now do work in your scene instead of only answering questions about it. Autodesk announced it on November 18 as a Tech Preview, alongside MCP servers that let outside AI agents connect to both apps and a faster Arnold viewport. We haven't tried any of it, so this is based on Autodesk's two blog posts, its Maya help pages, and Digital Production's write-up.

## What changed

When Maya 2027 introduced Autodesk Assistant, it was a help tool: ask how a feature works, or ask about what's in your scene. The new part, labeled "Do tasks for you," lets it act. Autodesk's examples include scene checks and UV mapping, and Digital Production adds cleanup, material management, and building a custom interface, mostly shown in 3ds Max. Autodesk says it needs no setup and comes with skills Autodesk built.

The guardrails are the interesting part. You choose read-only or read-write access, and read-write is off by default. With it on, the Assistant proposes a script and nothing runs until you click Allow. Each action it takes is a single undo step. A Safe Mode, also on by default, blocks scripts that reach outside your scene to read, change, or delete files on your computer, or run system commands.

Maya and 3ds Max also each get an MCP server, also a Tech Preview, so an outside agent you already use can drive the app. The only one Autodesk and Digital Production name is Claude, in an example where a tools developer has it run Maya unit tests and report back. The same controls apply: scene writes are opt-in, scripts need approval, and you can generate a fresh authentication token each time the server starts or keep one until you ask for a new one.

Separately, Arnold gets a new viewport mode in both apps that uses NVIDIA's DLSS to upscale and denoise the image while you move around, and Autodesk says it reduces how much data has to pass from Maya to Arnold on frame changes. Digital Production says you turn it on by choosing Arnold as the viewport renderer and enabling Accelerated Viewport in the toolbar.

## Why it matters for designers

A lot of 3D time goes to the chores around the actual modeling and lighting: checking a scene before handoff, cleaning up names and materials, unwrapping UVs. Studios have long handled that with custom scripts, which only helps if someone on the team writes them. Describing the job in a sentence and reviewing the script before it runs puts some of that within reach of artists who don't code.

The approval step also sets a useful baseline. Plenty of AI tools now edit files directly. Having writes off by default, a visible script to approve, one undo step per action, and a block on touching anything outside the scene is a sensible model, and it's worth asking for the same from other tools.

If you'd rather not use any of it, nothing changes. Read-write access is off unless you switch it on.

## What to watch out for

This is a Tech Preview, so expect rough edges and changes. Autodesk's posts don't say whether the Assistant runs in the cloud or needs an internet connection, so check before using it on a locked-down or offline machine.

Approving a script only protects you if you read it. A single undo step per action helps, but save a copy of the scene before pointing the Assistant at a client file, and check its results, especially for something like UV layout where a quick glance can miss problems.

The MCP server opens the app to an outside agent, and that agent's pricing, data handling, and mistakes are separate from Autodesk's. Keep Safe Mode on and write access off until you know what the agent is going to do.

For the Arnold viewport, Digital Production notes that the accelerated view takes pixels straight from the renderer and skips Arnold imagers, including color corrections and output denoisers, which production renders still apply. Compare a frame through both before signing off on a look.
