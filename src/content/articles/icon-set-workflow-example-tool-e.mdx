Generating one good icon with an AI tool is easy. Generating twelve that look like they belong together is the actual problem. Here's the workflow we landed on with Example Tool E.

## Why this works

Most icon-set drift comes from regenerating each icon from a fresh prompt. Anchoring every generation to the same reference image keeps line weight, corner radius, and perspective consistent across the set.

## Tutorial

1. **Design one "anchor" icon by hand or by prompt**, and refine it until you're happy with its style — line weight, corner radius, and level of detail.
2. **Export the anchor as a reference image** at a plain, transparent background.
3. **Generate the remaining icons using the anchor as a style reference**, keeping the subject-only portion of the prompt short and specific (e.g. "a magnifying glass" rather than a long descriptive paragraph).
4. **Batch-export at your target size** and check every icon against the anchor at actual size, not zoomed in.
5. **Hand-correct outliers.** Expect one or two icons per set to need manual cleanup in a vector editor — treat the generated set as a strong first draft, not a final deliverable.
6. **Re-export the whole set together** once corrections are made, so file naming and sizing stay consistent.

## Where it breaks down

Very abstract concepts (things with no obvious physical form) tend to drift most from the anchor style. Budget extra manual cleanup time for those.
