Webflow's MCP server has mostly been about building: making pages, filling the CMS, adding interactions. An update on October 15 adds the other half. The same agent can now read how the site is actually doing, and Google Gemini is now one of the assistants you can connect it to.

## What changed

Agents connected to Webflow's MCP server can now read from three of Webflow's measurement tools:

- **Analyze**: page-level traffic and goal data. Agents could already read site-level numbers, so the change is going page by page.
- **Optimize**: your A/B tests and experiments and their results, including which variation is winning. Webflow says creating and editing experiments through agents is still in development, so for now it's read-only.
- **AEO Analytics**: the pages LLM crawlers request most (filterable by provider and crawler category), plus your tracked prompts and how answer engines responded to them.

Webflow's pitch is that you can ask one question across all three, something like "which pages lost traffic this week, how are my experiments doing, and what are AI crawlers reading," and get it back in one answer.

There's also a new Team Administration piece that lets an agent or script invite people, change roles, and remove access to a workspace and its sites, limited to what the prompting person's own role allows.

On the connection side, Gemini now works with Webflow's MCP server alongside Claude and ChatGPT. Through it you can build pages and components, manage CMS collections, add interactions, ask about traffic, and run SEO, AEO, and accessibility checks without leaving Gemini.

## Why it matters for designers

If you hand off Webflow sites and stay on for maintenance, this closes a loop that usually lives in a separate dashboard. You can change a hero headline through an agent and, a week later, ask the same agent whether that page's traffic or goal completions moved. That's a faster way to answer the "did it work?" question clients always ask.

The AEO data is the newer, less familiar part. Seeing which pages AI crawlers actually request is a useful prompt for deciding which content to tighten up first. Webflow itself is careful to say a crawler requesting a page doesn't mean an answer engine used it, so it's a signal, not proof.

And if your team lives in Gemini rather than Claude or ChatGPT, you no longer have to switch assistants just to work on a Webflow site.

## What to watch out for

The agent can only read what you already have. Webflow says MCP access is included if you have access to Analyze, Optimize, and AEO Analytics, so if a client site doesn't use those, there's nothing new for the agent to pull.

The Gemini connector is limited for now: English in the United States, personal Google Accounts only, with Gemini Enterprise support (and support for Webflow Enterprise plans) still in development. And it doesn't use Webflow AI credits "at this time," which reads like a policy that could change.

Finally, an agent summarizing analytics is still an agent summarizing. Before you take a "traffic dropped because of X" conclusion to a client, check the actual numbers in Analyze yourself.
