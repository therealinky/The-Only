Framer published a changelog entry on September 22, 2026 introducing Skills: a way to save instructions that its AI agent reuses across tasks, instead of you re-explaining the same conventions in every prompt.

## What changed

Until now, getting consistent output from Framer's agent meant repeating context in each request — "use our brand colors," "match the tone of the rest of the site," "these CMS fields work this way." Skills lets you save that context once, as reusable instructions covering things like a design system, a writing style, or a CMS workflow, and reference it across tasks going forward. The feature also supports referencing specific project elements — pages, components, and styles — by name inside a Skill, so the agent can be pointed at "the primary button component" or "the pricing page's layout" rather than having that described from scratch. Framer's changelog frames control as staying with the user: the agent follows the saved instructions, but the person driving it keeps control of the result on the canvas.

## Why it matters for designers

This is aimed at a specific friction point in agent-assisted design work: an agent that's generically capable but doesn't know your specific conventions produces output that's technically fine and practically unusable — off-brand colors, a CMS structure that doesn't match your existing content model, copy in the wrong voice. Saving that context once, instead of re-typing it into every prompt, is the difference between an agent that has to be corrected every time and one that starts closer to right.

For teams maintaining a consistent design system across a large site, or an agency running the same conventions across multiple client projects, this is also a way to encode institutional knowledge somewhere more durable than a Slack thread or a designer's memory — provided the Skills themselves get kept up to date as the system evolves.

## What to watch out for

We haven't tested Skills hands-on yet, so the fields above are unverified. Worth checking directly before relying on it for client work: whether a Skill is scoped to one project or shared workspace-wide (relevant if you work across multiple clients in one Framer workspace), and whether it's practical to keep a saved Skill in sync as your actual design system changes.
