Figma has added a 3D transform effect. The short version from the release note: you can now tip a layer back in space instead of only spinning it flat. This is based on Figma's own release note and help page, and we haven't tried it ourselves.

## What changed

The note, dated November 12, 2026, says that with 3D transform you can "rotate objects along the x, y, and z axes." It describes on-canvas rotation handles with a live preview, and controls for perspective and depth when you're building a 3D scene.

It also names a few connections. It says the effect pairs with Figma Motion for animating flips and turns. It says you can copy CSS from Dev Mode or send a design to a coding agent through the Figma MCP. And it says you can let the Figma agent compose 3D designs for you.

Figma's help page fills in the rest. 3D transform is on all plans, for anyone with a Full seat and edit access, and it works on vectors, images, frames, components, and text. It's non-destructive, so layers stay editable and you can hide or remove the effect. To make several layers share one 3D space, like the faces of a cube, you turn on Keep nested layers 3D on the parent frame. That comes with a catch: the parent's opacity control is disabled, blend modes, shaders, other effects, and clip content stop working there, and its own fills and strokes are hidden. You can flatten the composition back to a 2D plane when you need those again.

## Why it matters for designers

Fake depth has been a chore in Figma for a long time. Card flips, tilted device mockups, and perspective hero shots usually meant a plugin, a trip to another tool, or a pre-rendered image. Doing it with a handle on the canvas, and with a live preview, should make small touches like a tilted product card much faster to try.

The Motion and CSS mentions are the interesting part for UI work. A flip you animate in Figma Motion, and a transform you can copy out of Dev Mode, are closer to what a developer actually builds than a flattened image of the same thing.

## What to watch out for

A transform that looks right in Figma still has to be built in code. The help page maps Keep nested layers 3D and the flat-plane option to CSS's `transform-style: preserve-3d` and `flat`, which is a good sign, but it doesn't promise the copied CSS matches the canvas pixel for pixel. Check it in a real browser before you promise a client the exact same tilt.

If a 3D composition suddenly loses its frame's fill, shadow, or clipping, that's Keep nested layers 3D at work, not a bug.

Perspective can also cost legibility. Text that's rotated off-axis is harder to read, so look at it at actual size before you commit.

Finally, if you use the Figma agent to compose 3D designs, treat the result as a starting point and inspect each layer. The sidebar lists what we couldn't confirm.
