Figma has made its Select area image tool quicker to use. According to the November 6 release note, you can click an object in an image and Figma selects it for you, so you don't have to trace its outline by hand. This is based on Figma's own notes and help page. We haven't tried it ourselves.

## What changed

Select area is the first step for Figma's AI Erase and Isolate. Per the help page, you select an image, open Select area from the toolbar, cover the object or area with the lasso, then choose Erase to remove it or Isolate to turn it into its own image layer.

The new part is the click. The release note says one click on an object makes Figma select it, which replaces the careful lasso drag for objects with clear edges. The note describes it as available on the macOS desktop app only. It doesn't list any other limits or say which plans get it, and it isn't labeled as a beta. Figma's help page hadn't caught up when we checked: it still describes only the lasso, so on a Mac the app and the docs won't match for now.

Separately, the help page says the image tools work on all plans, with edit access to the file, and that on the Starter plan they work only in Figma Design. Select area itself also works in FigJam, Figma Slides, and Figma Buzz, but the release note only tags Figma Design, so it's not clear whether one-click selection reaches those apps.

## Why it matters for designers

Cleaning up a stock photo or a product shot inside a layout used to mean a round trip to a photo editor, or a slow, wobbly lasso. A single click that grabs the whole object makes the small jobs feel small: pull a subject out as its own layer for a collage, or erase a stray item from the corner of a hero image without leaving the file.

It also fits how a lot of UI and web work goes. The image is rarely the main event, so a fast fix in the design file beats a trip to another app.

## What to watch out for

The click selection is Mac desktop only, so teammates in a browser or on another system still get the lasso. Don't assume a shared file will behave the same on every machine.

Every action draws on Figma's shared AI credits. A June reply from Figma Community Support on the forum says that when the monthly limit runs out, these tools can stop processing silently, so if a selection seems to do nothing, check your AI balance before you go hunting for another cause.

And as with any generative fill, check the result at full size. Edges, shadows, and anything the removed object was touching are where a rushed fix usually shows. The sidebar lists what we couldn't confirm.
