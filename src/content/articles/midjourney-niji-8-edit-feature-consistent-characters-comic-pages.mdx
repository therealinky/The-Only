Midjourney and Spellbrush have released Niji 8, the newest version of the anime and illustration model that runs inside Midjourney. The headline for illustrators is the return of consistent characters: instead of the character reference feature that Niji 6 had, Niji 8 gets an edit feature that poses an existing character into new scenes.

It also changes how prompts behave in a way worth knowing before you rerun old ones.

## What changed

To use it, add `--niji 8` to your prompt in Discord, or pick "Niji 8" from the Version dropdown in the settings panel next to the prompt bar on the web.

- **An edit feature for consistent characters.** Press the quick edit button at the bottom right of a finished image, and you can attach more images and describe what you want. The announcement's suggested approach is two images: a character sheet and a background, with a prompt asking to put the character from one into the other. One image works too, for things like a new pose or a small touchup such as adding a hair bun. The post warns that blurry or pixelated inputs give weaker results.
- **Better spatial prompt following.** Prompts that place specific objects in specific relationships to each other come out more reliably, according to the announcement.
- **Simple comic pages.** You can describe a page panel by panel (top, middle, bottom) and get a basic manga layout from a single prompt.
- **More variety from short prompts.** Niji 7 tended to give you the same character every time you typed the same words. Niji 8 won't. It's meant to combine Niji 7's look with Niji 6's range, and it treats a longer prompt as a sign you know what you want, so longer prompts return less varied results.
- **Speed and HD.** The niji・journey team calls it the fastest and most coherent Niji model so far, and recommends trying HD with it.

The team says it held the launch until characters could be reproduced through the edit feature, and that style references and moodboards were improved for the same reason.

## Why it matters for designers

For illustrators using Niji for character work, losing character reference in Niji 7 was a real gap. The workaround was writing the exact same description every time and hoping the model locked in. Niji 8 flips that: the prompt is for exploring, and the edit feature is for keeping a character on model once you've chosen one. That's closer to how character design actually works: wide exploration first, then consistency.

Comic page layouts and better spatial prompting are useful for storyboards, thumbnails, and pitch pages, where you need the right things in the right places more than you need a finished image.

If you're skeptical of generated illustration, the shift is still worth knowing about: an edit feature that takes your own character sheet as input makes it easier for others to produce new images of an existing character, which is exactly where questions about style and ownership get sharper.

## What to watch out for

Old prompts will behave differently. If you relied on Niji 7 returning the same character from the same words, Niji 8 is designed not to do that, so plan on moving that work to the edit feature.

Midjourney's documentation hasn't caught up yet. As of November 27, its Version page doesn't list Niji 8, and its Edit Model page describes the Edit model as compatible with V8.1 and V8.2, not working with `--tile`, and producing results that don't work with Remix. It also says Midjourney's V8 Edit model takes up to four reference images and replaces Character Reference and Omni Reference there. Whether any of that applies to Niji 8's edit feature isn't stated, so test before you build a process around it. The announcement also only covers Discord and the web, not the niji・journey mobile app.

Privacy is the other thing to check. By default, Midjourney images are public, and its docs say Edit model creations appear on midjourney.com unless you have Stealth Mode, which only comes with Pro and Mega. That covers images you upload, not just the results, so a client's unreleased character sheet could end up visible to other members. Stealth helps, but Midjourney's terms only promise "best efforts" not to publish, and you still grant Midjourney a broad license to what you upload. See the sidebar for rights and cost details.
