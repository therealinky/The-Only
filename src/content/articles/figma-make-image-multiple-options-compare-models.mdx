Figma's image tools used to give you one picture per prompt. If it wasn't right, you prompted again. A November 18 release note changes that: Make image and Edit image can now return several options at once, or the same prompt run through more than one model. This is based on Figma's release note and help pages. We haven't tried it ourselves.

## What changed

There are two new ways to get more than one result.

The first is more options from one model. Figma's help page says you open the model picker and choose 2, 4, or 6 images, and the model generates that many from your single prompt.

The second is comparing models. The release note says you can run a prompt across up to three image models at once and see each one's take side by side. In the help page's words, you click the plus next to another model to add it, and you get one image per model you picked. When you're filling a layer, you can hover over each option to preview it in place, or place them all on the canvas to compare.

The release note tags Figma Design, FigJam, Figma Slides, and Figma Draw. The help page lists the image tools as available on all plans with edit access to the file, with one exception: on the Starter plan, the AI image tools only work in Figma Design.

## Why it matters for designers

A lot of image prompting is really about picking. You rarely know what you want until you see a few versions, and one-at-a-time generation makes that slow. Getting a spread of options in one go is closer to how you'd brief an illustrator or browse stock: look at several, then choose.

The model comparison is the more interesting part. Different image models have very different habits with text, faces, lighting, and style. Seeing them next to each other on the same prompt is a quick, practical way to learn which one suits a placeholder hero, a product mockup, or a mood board, instead of guessing from model names.

## What to watch out for

Cost is the big one. Figma's credits page lists image generation per image, and the rate varies a lot by model, so a six-image run or a three-model comparison isn't free exploration. At Figma's listed rates, six options on Nano Banana 2 cost 96 credits, while one image from each of the three models costs 24. On a Starter plan or a View seat, with a daily limit of 150 credits, a single six-image run on the priciest model uses most of a day's allowance. If you're on a team, it's worth knowing whether your admin has set credit limits.

More options also means more to review. It's easy to grab the first one that looks fine at thumbnail size. Check the one you pick at full size, especially hands, text in the image, and edges where it meets your layout.

And comparing models means your prompt goes to more than one of them. The sidebar notes what we couldn't confirm about how prompts and images are handled.
