Most image models make you fight for composition. You write "logo top left, product center, headline along the bottom" and hope. Black Forest Labs' FLUX 3 Image, announced on October 1, takes a different approach: you lay the image out first.

## What changed

FLUX 3 Image is Black Forest Labs' new model for generating and editing images. The headline feature is layout boxes. You place each element on a canvas with a bounding box and a short description, and the model generates an image that keeps those elements where you put them. According to Black Forest Labs, the canvas is a 0 to 1000 grid on both axes, and in the Playground you can simply draw the boxes by hand.

The same idea carries over to editing. You can re-describe, replace, or move an individual box, and the documentation shows edits phrased as "keep the rest of the image unchanged," with the parts you want preserved marked as anchors. Black Forest Labs' pitch is that you can make several edits at once without changing anything else.

A few other details from the model page and docs:

- It accepts up to 10 reference images, each one tagged so your prompt can refer to it.
- It generates natively at 2K and 4K.
- Text in a layout is given as exact strings, and the docs' edit examples ask for existing text to be kept unchanged.
- An optional upsampler expands short requests into fuller captions, and Black Forest Labs says it leaves your drawn boxes alone.

You can use it in the browser Playground or through the API. Companies can also license the weights to run and fine-tune it on their own infrastructure.

## Why it matters for designers

Layout is the part of image generation that's hardest to direct with words, and it's the part designers care most about. Drawing a box for the product, a box for the headline, and a box for negative space is how a lot of us already think about a composition, so being able to hand the model that structure is a real shift from prompt-and-pray.

The region editing matters just as much. A common frustration with AI images is fixing one thing and watching something else drift. If moving the product or swapping a background object really does leave every other part alone, that makes iterating on a key visual or a campaign variant far less painful. (Ideogram's 4.5 edit model, which we covered on October 5, is chasing the same problem from a different angle.)

## What to watch out for

This is mostly an API and Playground model right now, not a button inside a design app you already use. The box coordinates are written as numbers in the API, so outside the Playground you'll want a tool or plugin that turns drawn boxes into that format.

"Without changing any other pixel" is Black Forest Labs' claim, not something we've tested. Zoom in and compare before and after on anything that matters, especially faces, small text, and product details.

Pricing is murky. The model page doesn't list prices, and the third-party listings we found don't agree with each other, so check Black Forest Labs' own pricing before relying on it for volume work. Reports also mention open weights for a related FLUX 3 model coming later, but the model page only describes a commercial license for FLUX 3 Image, so don't plan on a free local version yet.
